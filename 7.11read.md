Ответ на контрольный вопрос 1:

Рекурсия — это метод программирования, при котором функция вызывает саму себя для решения задачи, разбивая её на более простые подзадачи.

Два обязательных компонента рекурсивной функции:

1. Базовый случай (base case) — условие, при котором рекурсия завершается, и функция возвращает результат без дальнейших вызовов самой себя. Это предотвращает бесконечную рекурсию.
   Пример: для факториала — if (n == 0 || n == 1) return 1;
2. Рекурсивный случай (recursive case) — часть функции, в которой она вызывает саму себя с изменёнными параметрами, приближающими решение к базовому случаю.
   Пример: для факториала — return n * factorial(n - 1);
