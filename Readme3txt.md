1. Сортировка выбором (Selection Sort) - C++
   Алгоритм последовательно находит минимальный элемент в неотсортированной части массива и обменивает его с текущим элементом. Массив разделяется на отсортированную и неотсортированную части. На каждой итерации находится минимальный элемент в неотсортированном сегменте, который затем перемещается в конец отсортированной части. Процесс повторяется до полного упорядочивания.
2. Сортировка пузырьком (Bubble Sort) - Python
   Алгоритм многократно проходит по массиву, сравнивая соседние элементы и меняя их местами при нарушении порядка. На каждой итерации наибольший элемент перемещается в конец массива. Процесс продолжается до тех пор, пока не будет выполнено ни одного обмена за полный проход.
3. Сортировка вставками (Insertion Sort) - C++
   Алгоритм построчно формирует отсортированную часть массива, вставляя каждый следующий элемент в правильную позицию. Элементы, превышающие вставляемый, сдвигаются вправо. Процесс продолжается до полного упорядочивания всех элементов.
4. Сортировка слиянием (Merge Sort) - C++
   Алгоритм использует принцип "разделяй и властвуй", рекурсивно разделяя массив на две половины до получения подмассивов из одного элемента. Затем происходит слияние отсортированных подмассивов в правильном порядке.
5. Быстрая сортировка (Quick Sort) - Python
   Алгоритм выбирает опорный элемент и разделяет массив на две части: элементы меньше опорного и элементы больше опорного. Затем рекурсивно применяет ту же процедуру к обеим частям.
6. Пирамидальная сортировка (Heap Sort) - C++
   Алгоритм преобразует массив в двоичную кучу, затем последовательно извлекает максимальный элемент и перестраивает кучу. Этот процесс повторяется до полной сортировки массива.
7. Сортировка подсчетом (Counting Sort) - Python
   Алгоритм работает путем подсчета количества каждого уникального элемента в массиве. Затем вычисляются позиции элементов в отсортированном массиве на основе полученных счетчиков.
8. Поразрядная сортировка (Radix Sort) - C++
   Алгоритм сортирует числа по отдельным цифрам, начиная с младшего разряда. Для каждого разряда применяется стабильная сортировка, сохраняющая относительный порядок элементов с одинаковыми значениями текущего разряда.
9. Сортировка Шелла (Shell Sort) - Python
   Алгоритм представляет собой усовершенствованную версию сортировки вставками. Элементы сортируются с определенным интервалом, который постепенно уменьшается до единицы.
10. Сортировка перемешиванием (Cocktail Shaker Sort) - C++
    Улучшенная версия пузырьковой сортировки, которая проходит по массиву в обоих направлениях. На каждом проходе наибольший элемент перемещается в конец, а наименьший - в начало массива.
11. Гномья сортировка (Gnome Sort) - Python
    Простой алгоритм, который работает подобно садовому гному, сортирующему цветочные горшки. Элементы последовательно сравниваются и перемещаются вперед или назад, пока не займут правильные позиции.

Все алгоритмы имеют различные показатели временной сложности - от O(n log n) для эффективных алгоритмов до O(n²) для простых методов сортировки. Выбор конкретного алгоритма зависит от размера данных и требований к производительности.
