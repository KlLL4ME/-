1. Сортировка выбором (Selection Sort) - C++  
Алгоритм последовательно находит минимальный элемент в неотсортированной части массива и меняет его местами с текущим элементом.

2. Сортировка пузырьком (Bubble Sort) - Python  
Алгоритм многократно проходит по массиву, сравнивая соседние элементы и меняя их местами при неправильном порядке.  
for j in range(0, n - i - 1): - цикл по неотсортированной части  
if arr[j] > arr[j + 1]: - сравнение соседних элементов  
arr[j], arr[j + 1] = arr[j + 1], arr[j] - обмен элементов

3. Сортировка вставками (Insertion Sort) - C++  
Алгоритм строит отсортированную последовательность, вставляя каждый следующий элемент в правильную позицию.  
int key = arr[i] - текущий элемент для вставки  
while (j >= 0 && arr[j] > key) - поиск позиции для вставки  
arr[j + 1] = key - вставка элемента на найденную позицию

5. Сортировка Шелла (Shell Sort) - Python  
Улучшенная версия сортировки вставками с использованием убывающих промежутков.

8. Последовательный поиск (Linear Search) - Python  
Поиск элемента последовательным перебором всех элементов массива.  
for i in range(len(arr)): - цикл по всем элементам  
if arr[i] == target: - проверка совпадения  
return i - возврат индекса найденного элемента

9. Бинарный поиск (Binary Search) - C++  
Алгоритм работает с отсортированным массивом, последовательно уменьшая диапазон поиска.

left = mid + 1 - сужение диапазона поиска вправо
